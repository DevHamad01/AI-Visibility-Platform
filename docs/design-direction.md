# Signal design direction

Warm paper canvas, white cards, ink text and an indigo accent make dense analytics readable. Dark mode uses navy surfaces and light indigo. Every status has a text label. Typography uses system sans-serif, 14px body and 28–36px page titles; metrics use tabular numerals. Spacing uses a 4px base, 24px card padding, restrained shadows and thin borders.

Desktop uses a persistent rail; tablet uses horizontal navigation. Tables scroll inside cards. ECharts heatmaps distinguish missing data from measured absence, with tooltips and an accessible text table. Trends only plot measured runs. Loading, empty, error and partial views are first-class states. No mock analytics ship in the application.
